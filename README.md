# Property Portal Mobile

The Expo app is the planned mobile companion to the Property Portal. It will use the same API as the web portal and will not keep separate property or account rules.

## Run locally

```powershell
npm install
npm start
```

Expo opens the development tools for running the app on a simulator or device.

## Planned mobile features

- Sign in and account access.
- Browse and search sale and rental listings.
- View property images and details.
- Save favorites and send or review inquiries.
- Support selected owner and agent listing tasks.

The current app is a starter screen; these mobile workflows are planned after the web experience is established.
